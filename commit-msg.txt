feat(playground,api): data-safe drafts, preview hardening, trash and revisions, narrow studio

Drafts and saving
- Stash unsaved account-project edits before New/Import/Remix; restore keeps their version
- saveDraft reports refused writes ("Not saved" chip, warn before leaving);
  draft writes debounced 800ms and flushed on leave/unmount/New/Import
- A failed ?project= load shows an error instead of opening an unrelated draft
- Account workspace ids are never used as browser keys; signed out, such links ask to sign in
- Home: review browser-only projects and save chosen ones to the account
- Autosave retries network/5xx errors; one project create at a time
- PATCH /projects/:id checks the version it read (no stale rename overwrite)

Security
- Preview frame: per-frame token on messages, reload if it navigates away,
  web links open a new window, forms never submit
- Contract-function drops validated like Contracts panel input (parseContractDrop)
- ALLOW_TEST_LOGIN requires a loopback HOST for every NODE_ENV
- Gallery code pins the signer and uses versioned unpkg embed URLs
- Admin release links limited to https GitHub run pages
- vite preview CORS limited to /assets/*
